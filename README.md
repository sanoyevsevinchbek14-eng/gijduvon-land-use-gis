# gijduvon-land-use-gis

GIS and remote sensing workflows for monitoring agricultural land use
in Gijduvon district, Bukhara region, Uzbekistan.

## Goal
Reproducible methods for detecting land-use change using multi-date
Sentinel-2 imagery and GIS analysis.

## Status
Early stage. Scripts and documentation will be added.

## Data
Only open and non-confidential data are published here.
